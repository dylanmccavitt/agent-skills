# Receipt: TASK

- **Outcome:** WHAT CHANGED AND WHY
- **Where:** BRANCH, PR, AND KEY FILES
- **Evidence:** CHECKS RUN AND RESULTS, AT HEAD SHA
- **Skipped or blocked:** CHECKS NOT RUN AND WHY, OR NONE
- **Open questions:** DECISIONS THE USER STILL OWNS, OR NONE
- **Next action:** THE EXACT NEXT STEP
